อธิบายคำสั่งที่ใช้

 เริ่มจากการสมัครบัญชี หน้า: CreateAccountScreen ผู้ใช้กรอกอีเมล, รหัสผ่าน และยืนยันรหัสผ่าน เมื่อผู้ใช้กดปุ่ม "สร้างบัญชี" ระบบจะตรวจสอบว่ามีการกรอกข้อมูลครบถ้วนหรือไม่ และตรวจสอบว่ารหัสผ่านทั้งสองตรงกันหรือไม่ หากข้อมูลถูกต้อง, Firebase Authentication จะใช้ฟังก์ชัน createUserWithEmailAndPassword เพื่อสร้างบัญชีผู้ใช้ใหม่ เมื่อบัญชีถูกสร้างสำเร็จ, ผู้ใช้จะถูกพาไป หน้า: login_screen.dart

 เข้าสู่ระบบ หน้า: LoginScreen ผู้ใช้กรอกอีเมลและรหัสผ่านเมื่อผู้ใช้กดปุ่ม "เข้าสู่ระบบ", ระบบจะตรวจสอบว่าได้กรอกข้อมูลครบถ้วนหรือไม่ หากข้อมูลถูกต้อง, ระบบจะใช้ฟังก์ชัน signInWithEmailAndPassword ของ Firebase เพื่อเข้าสู่ระบบและผู้ใช้จะถูกพาไปหน้าหลัก (HomeScreen)

  ออกจากระบบ หน้า: HomeScreen เมื่อผู้ใช้กดปุ่ม "ออกจากระบบ", ระบบจะใช้ฟังก์ชัน signOut ของ Firebase เพื่อทำการออกจากระบบและไปยังหน้าหลัก

   การรีเซ็ตรหัสผ่าน หน้า: ForgotPasswordScreen ผู้ใช้กรอกอีเมลที่ต้องการรีเซ็ตรหัสผ่านและเมื่อผู้ใช้กดปุ่ม "ส่งอีเมลสำหรับรีเซ็ตรหัสผ่าน", ระบบจะใช้ฟังก์ชัน sendPasswordResetEmail ของ Firebase เพื่อส่งอีเมลให้ผู้ใช้สำหรับรีเซ็ตรหัสผ่านซึ่งทำให้ผู้ใช้สามารถตั้งรหัสผ่านใหม่ได้
